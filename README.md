# 📚 מילונית כיס חכמה - RP2350 Touch LCD 2.8
### Smart Bilingual Pocket Dictionary & Speech Synthesizer (Hebrew ⟷ English)

פרויקט מילונית כיס דיגיטלית חכמה, דו-כיוונית (עברית ⟷ אנגלית) עם הקראה קולית מובנית (Speech Synthesis), המיועדת לתלמידי **חטיבת ביניים ותיכון** (כולל תוכנית הלימודים ואוצר המילים של משרד החינוך לבגרות - Bands I, II, III ומאגר מילים מודרני מקיף).

המערכת רצה על גבי לוח **Waveshare RP2350-Touch-LCD-2.8** הכולל בקר **Raspberry Pi Pico 2 (RP2350)** מובנה, מסך מגע קיבולי (Capacitive Touch) צבעוני בגודל 2.8 אינץ', רמקול I2S מובנה, וחריץ לכרטיס זיכרון MicroSD.

---

## 🌟 תכונות עיקריות (Key Features)

1. **מאגר מילים ענק (מעל 21,600 ערכים!)**:
   - **10,292 מילים באנגלית** כולל כל אוצר המילים הנדרש לבגרות (Bands 1, 2, 3) ותרגומיהן המלאים לעברית.
   - **11,376 מילים וביטויים בעברית** ותרגומיהם המדויקים לאנגלית.
   - קובץ מילון בינארי מאונדקס (`dict.bin`) בנפח של כ-0.64MB בלבד, המאפשר חיפוש מיידי בסיבוכיות $O(\log N)$ ישירות מזיכרון ה-Flash של הלוח, ללא שיהוקים וללא ניצול מיותר של זיכרון ה-RAM.

2. **הקראה קולית ורמקול מובנה (Text-To-Speech & Audio)**:
   - מנוע סינתזה פונטית (Embedded Phonetic Formant Speech Synthesizer) המפיק הגיית מילים באנגלית דרך הרמקול המובנה (ממשק I2S חומרתי).
   - כפתור **`[🔊 הקרא]`** ייעודי המופיע לצד כל הגדרה ותרגום ומאפשר לשמוע את ההגייה של המילה באנגלית.
   - כפתור **שליטה בווליום (`[V:7]`)** בסרגל העליון – מעבר נוח בין דרגות עוצמה שונות ועד מצב השתקה (`MUTE`) בליווי חיווי צליל.
   - צלילי משוב נעימים: קליק עדין בהקלדה, צליל הצלחה (Chime) במציאת מילה, וצליל התראה מותאם לשגיאות כתיב.

3. **תיקון שגיאות כתיב אוטומטי (Typo Correction / Fuzzy Matching)**:
   - הקלדתם מילה עם שגיאת כתיב (למשל `beautifull` או `skool`)?
   - האלגוריתם מזהה זאת אוטומטית לפי מרחק לוונשטיין (Levenshtein Distance) ומציג **כפתורי הצעות לחיצים (Suggestion Pills)** של המילים הקרובות ביותר.
   - לחיצה בנגיעה על כל כפתור הצעה מציגה מיד את התרגום המלא ומשמיעה אותו.

4. **מסך מגע קיבולי רספונסיבי (Capacitive Multi-Touch)**:
   - דרייבר מותאם לבקר המגע הקיבולי **CST328 / CST3530**, המאפשר הקלדה קלה ורכה במגע אצבע (ללא צורך בלחיצה חזקה או עט מגע).

5. **תצוגת IPS חדה ללא הבהובים (Zero-Flicker Framebuffer)**:
   - ניצול מלא של ה-SRAM המורחב (520KB) של ה-RP2350 לצורך FrameBuffer שלם בגודל 153KB.
   - רענון מסך מלא בתוך 60 מילי-שניות דרך SPI במהירות 62.5MHz ללא שום ריצוד או קריעה בתמונה.

6. **מקלדת וירטואלית מלאה דו-לשונית**:
   - מקלדת אנגלית בתצורת QWERTY מלאה.
   - מקלדת עברית תקנית מלאה (כולל אותיות סופיות ך, ם, ן, ף, ץ).
   - כפתורי שליטה: רווח (`SPACE`), מחיקה (`<`), מעבר שפה (`[EN / עב]`), וחיפוש (`GO`).

7. **תמיכה מובנית בכרטיס זיכרון MicroSD**:
   - המערכת מזהה ומחברת אוטומטית כרטיס זיכרון MicroSD אם הוכנס, ומשתמשת בזיכרון ה-Flash הפנימי (16MB) במידה ואינו קיים.

## 🔌 מפרט חומרה וחיבורי פינים (Hardware Pinout)

הפרויקט מיועד ומכויל עבור **Waveshare RP2350-Touch-LCD-2.8**:

| רכיב | פין / ממשק ב-RP2350 | תיאור |
|---|---|---|
| **LCD ST7789** | `SPI1`: `SCK=GPIO10`, `MOSI=GPIO11` | תצוגת IPS ברזולוציה 320x240 |
| **LCD Control** | `CS=GPIO13`, `DC=GPIO14`, `RST=GPIO15`, `BL=GPIO16` | בקרת תצוגה ועוצמת תאורה (PWM) |
| **Capacitive Touch** | `I2C1`: `SDA=GPIO6`, `SCL=GPIO7` | בקר מגע קיבולי CST328 / CST3530 |
| **Touch Control** | `RST=GPIO17`, `INT=GPIO18`, `BAT_EN=GPIO26` | אינטראפט, איפוס והפעלת מתח |
| **I2S Audio DAC** | `BCK=GPIO2`, `LRCK=GPIO3`, `DIN=GPIO4` | יציאת אודיו דיגיטלית למגבר ולרמקול |
| **MicroSD Card** | `SPI0`: `SCK=GPIO18`, `MOSI=GPIO19`, `MISO=GPIO16`, `CS=GPIO22` | חריץ כרטיס זיכרון MicroSD |

## 🚀 מדריך התקנה פשוט (Step-by-Step Installation)

### שלב 1: התקנת קושחת MicroPython (Firmware)
1. חברו את הלוח למחשב באמצעות כבל USB-C תוך כדי **לחיצה רצופה על כפתור `BOOT`** (או לחיצה על `BOOT` ואז לחיצה קצרה על `RESET`).
2. המכשיר יופיע במחשב ככונן הבזק נייד בשם **`RP2350`**.
3. העתיקו לכונן את קובץ הקושחה הייעודי של הלוח:
   - הנתיב במאגר: `firmware/RP2350-Touch-LCD-2.8.uf2`
4. הלוח יאתחל את עצמו אוטומטית ויעלה כהתקן MicroPython עם יציאת COM טורית.

---

### שלב 2: העלאת קבצי הפרויקט למכשיר

הדרך הפשוטה והמהירה ביותר היא באמצעות הכלי הרשמי **`mpremote`** (ניתן גם באמצעות **Thonny IDE**):

ודאו שמותקן אצלכם `mpremote` (התקנה במידת הצורך: `pip install mpremote`).  
בדקו לאיזה פורט COM התחבר הלוח (למשל `COM20` או `COM21`), והריצו משורת הפקודה:

```bash
# החליפו את COM21 בפורט המתאים במחשב שלכם
python -m mpremote connect COM21 cp st7789.py :st7789.py
python -m mpremote connect COM21 cp cst328.py :cst328.py
python -m mpremote connect COM21 cp audio.py :audio.py
python -m mpremote connect COM21 cp font_data.py :font_data.py
python -m mpremote connect COM21 cp fonts.py :fonts.py
python -m mpremote connect COM21 cp keyboard.py :keyboard.py
python -m mpremote connect COM21 cp dictionary.py :dictionary.py
python -m mpremote connect COM21 cp dict.bin :dict.bin
python -m mpremote connect COM21 cp main.py :main.py

# הפעלה מחדש של המכשיר
python -m mpremote connect COM21 soft-reset
```

> **הערה:** העלאת קובץ המילון `dict.bin` (כ-650KB) אורכת כ-45–60 שניות. ברגע שההעלאה מסתיימת והמכשיר מאותחל, המילונית תעלה אוטומטית על המסך ותשמיע צליל פתיחה!

## 📁 מה להעלות ל-GitHub? (Project Structure)

הפרויקט כבר כולל קובץ `.gitignore` מסודר שמונע העלאת קבצים זמניים וכבדים.  
הקבצים שמומלץ וצריך להעלות למאגר ב-GitHub:

```text
PICOMILL/
├── main.py                  # התוכנית הראשית ולולאת ממשק המשתמש
├── st7789.py                # דרייבר תצוגה ST7789 320x240 מהיר מבוסס Framebuffer
├── cst328.py                # דרייבר מסך מגע קיבולי CST328 / CST3530
├── audio.py                 # מנוע אודיו I2S, אפקטי צליל ומסנתז דיבור פונטי (TTS)
├── keyboard.py              # מקלדת מגע וירטואלית דו-לשונית (עברית / אנגלית)
├── dictionary.py            # מנוע חיפוש בינארי מהיר O(log N) ותיקון שגיאות כתיב
├── fonts.py                 # מנוע רינדור פונטים עם תמיכה מלאה בכתיבה מימין לשמאל (RTL)
├── font_data.py             # נתוני הביטמאפ של הפונטים
├── dict.bin                 # קובץ המילון המאונדקס (10,292 מילים באנגלית + 11,376 בעברית)
├── build_super_dictionary.py# סקריפט לבנייה ועדכון מאגר המילון ממקורות שונים
├── build_font.py            # סקריפט ליצירת פונטים מותאמים
├── .gitignore               # סינון קבצים מיותרים בהעלאה ל-Git
└── README.md                # תיעוד הפרויקט ומדריך ההפעלה
```

## 💡 טיפים לשימוש (User Guide)

- **החלפת שפה**: לחצו על כפתור `[EN -> עב]` בסרגל העליון, או על כפתור `[עב/EN]` במקלדת.
- **השמעת הגייה**: לאחר מציאת מילה, לחצו על כפתור ה-`[🔊 הקרא]` הירוק כדי לשמוע את הגיית המילה באנגלית דרך הרמקול.
- **שינוי עוצמת השמע**: לחיצה על כפתור הווליום `[V:7]` בסרגל העליון תעביר בין עוצמות: `7` ⟵ `10` ⟵ `MUTE` ⟵ `3` ⟵ `6` ⟵ `8` ⟵ `10` ותשמיע צפצוף אימות.
- **שגיאת כתיב**: הקלדתם אות שגויה? יופיעו כפתורי הצעות תכולים עם המילים המתאימות ביותר. לחיצה עליהם תציג מיד את התרגום.
- **ניקוי**: לחיצה על כפתור `[CLR]` מנקה את שורת החיפוש ואת המסך.
